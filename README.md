**NusaData — Indonesia in Numbers.** A static, offline national statistics site for the Republic of Indonesia: 12 headline indicators (population, GDP, growth, GDP per capita, inflation, unemployment, poverty, life expectancy, the Gini ratio, internet use, exports and visitor arrivals) with hand-drawn SVG charts and full annual series from 2015, a two-series trend explorer, a sortable comparison table of all 38 provinces, and a sources & methodology page that names the publisher — BPS (Badan Pusat Statistik) or the World Bank — and the exact figure and period behind every number. Plain HTML, CSS and vanilla ES modules under `app/`, no build step, no network requests; `main.ts` hands the site in by copying `app/` and `screenshots/` to the output directory and writing its dossier.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a browser
# (any static file server pointed at app/ works just as well)
```
